# Hellotext editorial

Work in the article's publishing project and read its local integration guide.
This shared repository supplies authoring rules, not account access or publishing
permissions. Preserve the user's requested scope and publication workflow.

1. Read [the editorial guide](../../guide.md) and the complete target article.
2. For interface instructions, read [screenshots](../../screenshots.md). For
   customer-facing examples, read [messages](../../messages.md). Use both only
   when the article benefits from both.
3. Follow [the workflow](../../workflow.md) to preserve originals, prepare a
   focused batch, verify it and record actual publication separately from plans.
4. If adding the shared system to a project, read
   [integration and updates](../../integration.md). Use the application's
   existing renderer and export contract; do not invent another renderer.

Keep screenshot provenance and editable example definitions with the consuming
article. Do not describe a proposed example, generated bundle or local preview
as a published change. When blocked, continue independent preparation and record
what specific check or input remains.
